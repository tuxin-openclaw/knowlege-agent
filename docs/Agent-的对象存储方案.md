# Agent 的对象存储方案
- 原始文件存入对象存储
- 文件对应的名称、来源、切片等元数据写入关系型数据库
- 文件内容的文本分片会用嵌入模型向量化并存入向量数据库

## 流程
用户提问 -> 去向量库做语义检索 -> 得到相似度高的文本分片（附带文件ID） -> 根据文件ID到对象存储获取原始文件、原文片段内容 -> 原文+检索结果返回给用户

## 三个对象存储方案
1. 阿里云 OSS：共有云托管服务，不用自己维护服务器，按量自动扩容；
2. MinIO：Docker 快速私有化部署，海量并发会卡，适合本地测试、小型知识库使用；
3. RustFS：专为私有化海量文件场景打造，Rust 底层内存占用低，并发稳定。

所有对象存储服务都兼容 S3 协议，可以直接使用 AWS 官方 @aws-sdk/client-s3;
